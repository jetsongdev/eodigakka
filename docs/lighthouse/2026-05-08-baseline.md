## 주요 회수 가능 항목

### Performance — Reduce unused JavaScript (1,570ms 절감 가능)

| 청크 | unused / total |
|---|---:|
| `/_next/static/chunks/0_100922grz8c.js` | **275KB / 486KB** (≈57% 미사용) |
| `0luvts3tzy_ph.js` | 30KB / 49KB |
| `0dbswrlu8wd95.js` | 24KB / 71KB |

가장 큰 청크의 절반 이상이 모바일 첫 렌더에서 미사용. Mapbox / Recharts / Radix 중 한쪽 또는 framework 코드일 가능성. 동적 import / route-level split 검토 여지.

### Accessibility — 4종

1. **`color-contrast`**: 푸터 `#777` on white = ratio 4.29 (AA 4.5 미달). `#595959` 이하로 어둡게.
2. **`link-in-text-block`**: 푸터 링크 `#2d6da3` vs 주변 `#777` 텍스트 = ratio 1.77. 색상만으론 링크 식별 불가 → underline 또는 다른 시각 단서 추가.
3. **`landmark-one-main`** (Mobile only): `<html>`에 `<main>` landmark 없음. `app/layout.tsx` 또는 `app/page.tsx`에 `<main>` 래퍼 추가.
4. **`target-size`** (Desktop only): 일부 터치 타겟이 24×24 미만. 실제 모바일 측정에선 안 잡혔지만, 슬라이더 핸들/카세트 버튼 사이즈 점검 가치 있음.
