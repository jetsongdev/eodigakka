## UX 변경

이전 (snapshot 02·03):
```
[ 4억 v ] ~ [ 8억 v ]    ← 셀렉트 박스 2개, 12억까지
```

이후 (이 스냅샷):
```
[ ⏮ ] [ ⏪ ] [ ◀ ] ━━━●━━━━━━━━━━━●━━━ [ ▶ ] [ ⏩ ] [ ⏭ ]
0억                                       50억
```

- 듀얼 핸들 (`@radix-ui/react-slider`) — 드래그로 양 끝 동시 조정
- **카세트 metaphor 6 버튼**:
  - 좌측 `⏮ ⏪ ◀` → cashMin 만 변경 (-10억 / -1억 / -1천만)
  - 우측 `▶ ⏩ ⏭` → cashMax 만 변경 (+1천만 / +1억 / +10억)
  - 핸들 교차 방지: cashMin ≤ cashMax clamp
  - 한계(0/50억)에서 자동 정지
  - 좁히는 방향(min↑ / max↓)은 슬라이더 핸들 드래그
- ±10억 도입 근거: 강북 4~8억 → 강남 한남·압구정 30억대 점프 시 ±1억 30번 클릭 → 3번으로 단축
- 슬라이더 step 5천만원, 카세트 버튼은 1천만/1억 두 단위
- 0~30억 (CASH_MAX 200000 → 300000)
- 슬라이더 양 끝 0억/30억 가이드
