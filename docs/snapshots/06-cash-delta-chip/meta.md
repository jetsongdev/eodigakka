## 핵심 시각 변경 3종

### 1. Cash delta 칩 (자금 슬라이더 변경 피드백)

자금 범위 텍스트 옆에 둥근 배지로 추가/제거 동 카운트 표시:
- 초록 배경 `+N` — 슬라이더 변경으로 새로 매칭된 동 개수
- 빨강 배경 `−N` — 빠진 동 개수
- 다음 변경이 올 때까지 유지(자동 fade-out 없음). mode/size 변경 시 reset.

UX 의도: "내가 슬라이더를 어디로 움직였더니 결과가 어떻게 바뀌었나"를 정량적으로 즉시 알려줌. 색칠 변화만으로는 동의 개수 변화를 체감하기 어려움.

### 2. 결과 카드 위계 강화

기존: `조건 일치 27개 동, 모드 TRADE, 현금 40000~80000만원` — 한 줄 평문, 가독성 낮음.

신규: 두 줄 구조
- **22pt 큰 숫자** (초록색 강조) + `개 동 통과` (보조)
- 11pt 메타 라인: `매매 · 4억~8억 · M형`

핵심 정보(통과 동 개수)를 시각 위계 최상단에. 1억 이상 cash 값은 `만원` → `억` 단위로 자동 변환(`formatMan` 함수). 1억 미만은 `5천만` / `4500만` 식으로 자연스럽게.

### 3. 푸터 — 면책 고지 + 데이터 출처 + 데이터 최신일 + 앱 버전

페이지 하단 일반 푸터(non-floating). outer flex column로 지도 영역(`flex: 1`) + 푸터(`flex-shrink: 0`)로 레이아웃 분리. 두 줄 구성:

**1번째 줄 — 면책**
> 이 사이트는 임장 후보를 색칠지도로 제시할 뿐, 매매 권유나 투자 자문이 아닙니다. 결과는 RTMS 신고분 기준 통계로 단정문이 아닌 후보 제시이며, 실제 거래 판단은 사용자 본인 책임.

청사진 9원리 중 "단정문 금지 / Apply는 사람만" 정책의 사용자 가시 표기. `면책:` 라벨은 빨강 강조.

**2번째 줄 — 데이터 / 버전**
- **출처**: `국토교통부 RTMS` (data.go.kr 링크) / `V-World LSMD 법정동` (vworld.kr 링크) / `© Mapbox/OpenStreetMap`
- **데이터 최신일**: `RTMS 2026-05-03 신고분까지` — `mv_dong_stats`의 `MAX(contract_date)` 기준
- **앱 버전**: `v0.1.0 #4e02b3a` — semver + git short SHA. `next.config.js`에서 빌드 타임에 inject.

UX 의도: 신뢰성(출처) + 재현 가능성(데이터일자/버전) + 법적 보호(면책)를 한 곳에. 처음엔 좌하단 floating 박스로 시작했으나 면책 한 줄을 추가하면서 푸터로 전환 — floating에 묶기엔 텍스트가 길고, 지도 위에 떠있는 형태는 면책 같은 정적 정보에 덜 어울림.

ControlPanel 결과 카드 하단에 있던 `RTMS YYYY-MM-DD 신고분까지` 라인은 푸터로 이동해 중복 제거 — 카드는 폴리곤 카운트만 유지.
